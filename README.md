# PPWR para PME

[Português](#português) · [English](#english) · [Français](#français)

## Português

Aplicação gratuita para Windows que ajuda pequenas e médias empresas a perceber o que o Regulamento (UE) 2025/40, relativo a embalagens e resíduos de embalagens (PPWR), exige para cada embalagem.

**Descarregar:** abra a [versão mais recente](../../releases/latest) e descarregue o ficheiro `PPWR-para-PME-Setup-….exe`.

- Instala só para o utilizador atual; não precisa de permissões de administrador.
- O instalador não é assinado, por isso o Windows pode mostrar um aviso na primeira execução. Escolha "Mais informações" e "Executar assim mesmo".
- Todos os dados ficam no seu computador. A aplicação não envia dados para a internet.
- As regras são atualizadas quando possível, sem compromisso de prazo. Dentro da aplicação, use Sobre > Verificar atualização de regras.
- Sem internet, descarregue `ppwr-rules.zip` e `ppwr-rules.sha256` noutro computador, ponha-os na mesma pasta e use Sobre > Importar pacote de regras.

A aplicação é um apoio à conformidade. Não constitui aconselhamento jurídico.

## English

Free Windows application that helps small and medium-sized companies understand what Regulation (EU) 2025/40 on packaging and packaging waste (PPWR) requires for each packaging item.

**Download:** open the [latest release](../../releases/latest) and download the file `PPWR-para-PME-Setup-….exe`.

- It installs for the current user only; no administrator rights are needed.
- The installer is not signed, so Windows may show a warning the first time. Choose "More info" and "Run anyway".
- All data stays on your computer. The application does not send data to the internet.
- The rules are updated when possible, with no committed schedule. In the application, use About > Check for rule updates.
- Without internet, download `ppwr-rules.zip` and `ppwr-rules.sha256` on another computer, put them in the same folder and use About > Import rule pack.

The application supports compliance. It is not legal advice.
